### Notes on how I work

- A quote and a short written agreement come before any code — scope, price,
  and deadline in writing, not assumed.
- A set number of revision rounds is included in every quote. More than that
  gets its own quote, not scope creep.
- Full rights to the delivered code transfer once the project is paid in
  full, not before.
- If something I built breaks during the warranty period, that's on me to
  fix — no separate invoice for it.
